# Calibration Lab Management System

A Flask-based web application for managing calibration laboratory operations.

## Features

- Calibration record management
- Instrument and equipment tracking
- Calibration reports and documentation
- Web-based interface

## Technology Stack

- Python
- Flask
- HTML, CSS, JavaScript
- Database configured for the application

## Installation

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure the required environment variables.
5. Run the Flask application using `python app.py`.

## Usage

Open the application in your browser using the local address shown when the Flask server starts.
